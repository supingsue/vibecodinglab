# pdf2pptx — PDF 轉 PPTX 命令列工具

把 PDF 文件轉成 PowerPoint 簡報：每一頁 PDF 渲染成一張高解析度圖片、貼滿一張投影片，
頁面上的文字則抽取到該張投影片的「演講者備忘稿」，方便搜尋與複製。

轉出的投影片畫面與原始 PDF 完全相同，適合把講義、文件快速帶進 PowerPoint
繼續加頁、調整順序、與既有簡報合併使用。

## 安裝

需要 Python 3.10 以上。相依套件只有 `pymupdf` 與 `python-pptx`，pip 安裝即可，
不需要 Poppler 等外部系統套件：

```bash
pip install -r requirements.txt
```

## 使用方式

```
python pdf2pptx.py <輸入.pdf> [-o 輸出.pptx] [--pages 起始-結束] [--dpi 數值]
```

| 參數 | 說明 |
|------|------|
| `輸入.pdf` | 要轉換的 PDF 檔案路徑（必填） |
| `-o, --output` | 輸出的 PPTX 路徑。預設與輸入檔同目錄、同檔名，副檔名改為 `.pptx` |
| `--pages` | 頁數範圍，從 1 起算，如 `5-12` 或單頁 `7`。預設轉換全部頁面 |
| `--dpi` | 渲染解析度，預設 `200` |

### 範例一：整份轉換

```bash
python pdf2pptx.py 講義.pdf
```

輸出 `講義.pptx`，頁數與原 PDF 相同。轉換中會顯示 `[3/20] 轉換中…` 進度，
完成後顯示輸出檔路徑、總頁數與總耗時。

### 範例二：只轉指定頁數範圍

```bash
python pdf2pptx.py 講義.pdf --pages 5-12 -o 節選.pptx
```

只轉第 5 到 12 頁（含頭尾）。若範圍超出實際頁數，會轉換存在的部分並顯示警告，
例如「文件僅有 10 頁，已轉換第 5-10 頁」。

### 範例三：提高解析度輸出

```bash
python pdf2pptx.py 講義.pdf --dpi 300
```

以 300 DPI 渲染，畫質更細緻（檔案也會更大）；投影用途預設 200 DPI 通常已足夠。

## 轉換規則

- 投影片尺寸依 PDF 第一頁的長寬比自動決定：長寬比 ≥ 1.6 用 16:9（13.33 × 7.5 英吋），其他用 4:3（10 × 7.5 英吋）
- 每頁圖片等比縮放、置中貼入投影片；比例不同時完整顯示不裁切（允許留白）
- 頁面文字（保留段落換行）寫入該張投影片的演講者備忘稿；純圖片頁備忘稿留空
- 任何錯誤（檔案不存在、非 PDF、密碼保護、輸出不可寫入）都會顯示中文訊息、以結束碼 1 結束，且不留下不完整的輸出檔

## 已知限制

本工具刻意不做以下功能：

- ❌ 不做「版面重建」：不嘗試把 PDF 內容還原成可編輯的文字框、表格、圖案（投影片內容是整頁圖片，文字僅存在於備忘稿）
- ❌ 不做 OCR：掃描檔（圖片型 PDF）無法辨識文字，備忘稿會是空的
- ❌ 不做 GUI 圖形介面：僅提供命令列
- ❌ 不做雲端上傳、API 服務
- ❌ 不處理 PDF 內的超連結、表單欄位、註解
- ❌ 不支援密碼保護的 PDF

## 測試

```bash
pip install pytest
python -m pytest tests/ -v
```

測試會用 PyMuPDF 動態建立 3 頁測試 PDF，涵蓋頁數一致、備忘稿內容、
`--pages` 各種情境與錯誤處理。
